# 素材与中文图片

返回 [中文首页](../../README.md) · [素材生成脚本的葡语原说明](../../scripts/assets/README.md)

Habblaud 的大多数角色和家具由 `client/src/art` 程序化绘制，品牌标志、墙画、海报和分享图位于 `client/public/assets`。中文 Fork 的默认展示图是 [`og-image-zh-CN.png`](../../client/public/assets/og-image-zh-CN.png)：图中介绍语与四种运行环境已改成中文。`client/index.html` 的 Open Graph / Twitter 图片元数据指向这张图；原 `og-image.png` 留给葡语上游说明。`docs/screenshots/zh-CN/` 存放实际中文界面截图，主 README 只引用该目录的截图。

图片中的 **Habblaud** 是品牌专名，不翻译；无语言的像素装饰也无需改。可读的产品介绍语、界面截图、图注必须是中文。画布内的状态气泡和通知由运行时翻译层产生，切换到葡语时会改回葡语；模型回复、用户消息与工具结果保持原文。

## 两条素材路径

| 路径 | 内容 | 维护方式 |
| --- | --- | --- |
| `scripts/assets/specs.json`、`generate.mjs`、`postprocess.py` | 上游品牌标志、墙画、海报、原葡语分享图及 manifest | 生成脚本先取图，再确定性地像素化 |
| `client/public/assets/og-image-zh-CN.png` | 本 Fork 的中文分享图 | 单独生成并人工检查汉字和四种来源名称 |
| `docs/screenshots/zh-CN/` | 中文网页实际截图 | 在运行 Habblaud 的浏览器中截取虚构演示数据 |

上游 `postprocess.py` 的默认 `og` 目标仍是 `og-image.png`。若重跑完整素材管线，它会更新原图和 `manifest.json`，**不会自动维护中文分享图**。改中文介绍语时，要同步更新 `og-image-zh-CN.png` 与 `client/index.html` 的尺寸、替代文字，并检查文字可读性，不能只改文件名。

## 上游素材管线概览

上游图像生成脚本使用 `OPENROUTER_KEY` 和图像模型产出初稿；`postprocess.py` 再执行透明背景处理、像素网格降采样、调色板限制、去孤立像素及部分边框绘制。脚本中的 `.cache/` 保存原图和备选稿，不进入正式构建。Logo 小图和部分字体由 `pixelart.py` 手工逐像素绘制，目的是小尺寸仍可辨认。完整参数、画风试验和旧模型成本保留在 [原始素材说明](../../scripts/assets/README.md)，其中历史价格与模型列表不是当前报价。

常用入口如下；生成新图需要你自己的图像服务配置，普通 `npm ci && npm run build` 不调用图像服务：

```bash
node scripts/assets/generate.mjs list
node scripts/assets/generate.mjs gen
python3 -E scripts/assets/postprocess.py
python3 -E scripts/assets/test_pixelops.py
```

只更新中文截图或分享图时无需重新生成全部品牌资产。验收图片时实际打开 PNG/GIF：检查中文汉字、数字、来源名称、文字裁切和移动视口，而不是只看 `alt` 或生成提示词。公开截图使用演示 Agent，避免暴露真实会话、账户、路径和桥接令牌。
