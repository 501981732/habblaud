## 断线与审批边界

最终检查发现并修复了 DSH 在 Habblaud 重启后的恢复缺口：空传输队列只轮询会得到“实例未注册”，无法自行补发会话。现在先探测桥接可达性，再补齐历史和全部活跃会话的完整快照，等待发送完成后恢复轮询、消息与网页审批。

用最终构建的 DSH 适配器和真实本机 HTTP 服务做了重启验证：初始会话在线 → Habblaud 停止、适配器观察到失联 → Habblaud 重新启动 → 同一适配器自动恢复会话。此项 Cordis 数据为受控 fixture，模型调用为 0；没有重启用户原有 DSH 运行时。

回归覆盖重复事件、实例替换、旧实例不可夺回、失联与重新注册、历史来源隔离、审批取消/超时/晚到、无本地页面、会话切换和并行等待。DSH 的允许与拒绝只作用于本次请求；Pi 工具审批默认关闭，不提供虚假的“始终允许”。

DSH 原 Web UI 回退链有契约测试；实机触发过无 Habblaud 页面时的原审批等待入口，但本次没有完成原 Web UI 的人工点选回退验证。
